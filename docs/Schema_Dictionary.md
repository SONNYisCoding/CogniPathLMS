# Schema Dictionary - CogniPath LMS

This document serves as the single source of truth for all data structures, naming conventions, and models within the project.

---

## 1. Firestore Database Schema

### Collection: `users`
**Path:** `/users/{uid}`
| Field | Type | Description |
| :--- | :--- | :--- |
| `uid` | string | Unique identifier from Firebase Auth |
| `displayName` | string | User's full name |
| `email` | string | Primary email address |
| `photoURL` | string | URL to profile image |

#### Sub-collection: `paths`
**Path:** `/users/{uid}/paths/{pathId}`
| Field | Type | Description |
| :--- | :--- | :--- |
| `studentName` | string | Name used during generation |
| `title` | string | Title of the learning path |
| `overallGoal` | string | User's stated objective |
| `level` | string | Beginner, Intermediate, Advanced |
| `estimatedCompletionWeeks` | number | Timeline generated by AI |
| `createdAt` | string (ISO) | Timestamp of creation |
| `modules` | array[object] | Snapshot of module definitions (see below) |

#### Sub-collection: `modules`
**Path:** `/users/{uid}/paths/{pathId}/modules/{moduleId}`
| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | string | Module identifier |
| `title` | string | Module title |
| `content` | string | Generated markdown content |
| `status` | string | `not_started`, `in_progress`, `completed` |
| `lastAccessed` | string (ISO) | Timestamp of last visit |

#### Sub-collection: `messages` (Module or Path level)
**Path:** `.../messages/{msgId}`
| Field | Type | Description |
| :--- | :--- | :--- |
| `role` | string | `user` or `model` |
| `text` | string | Message content |
| `createdAt` | string (ISO) | Timestamp |

## 2. API Schema (Backend - Flask)

### Endpoint: `/api/generate-path`
- **Method:** POST
- **Input (FormData):**
  - `name`: string
  - `goal`: string
  - `level`: string
  - `files`: File[] (Multi-part)
- **Output (JSON):** Matches `PersonalizedPath` interface.

### Endpoint: `/api/generate-lesson`
- **Method:** POST
- **Input (JSON):**
  - `topic`: string
  - `description`: string
  - `userGoal`: string
- **Output (JSON):** `{"content": string}`

## 3. Frontend Types (TypeScript)

### Interface: `PersonalizedPath`
**Location:** `client/src/types/gemini.ts`
```typescript
export interface PersonalizedPath {
    studentName: string;
    title?: string;
    overallGoal: string;
    estimatedCompletionWeeks: number;
    level: string;
    modules: LearningModule[];
}
```

### Interface: `LearningModule`
```typescript
export interface LearningModule {
    id: string;
    title: string;
    duration: string;
    difficulty: 'Beginner' | 'Intermediate' | 'Advanced';
    topics: string[];
    description: string;
}
```

### Interface: `ModuleData` (Firestore record)
```typescript
export interface ModuleData {
    id: string;
    content: string;
    status: 'not_started' | 'in_progress' | 'completed';
    lastAccessed?: string;
}
```

## 4. Naming Conventions
- **Frontend/TypeScript:** `camelCase` (e.g., `displayName`, `overallGoal`).
- **Backend/Python:** `snake_case` (e.g., `user_id`, `context_text`).
- **Firestore:** Matches Frontend `camelCase` for direct serialization where possible.
